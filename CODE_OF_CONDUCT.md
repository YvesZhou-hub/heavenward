# Code of conduct

Heavenward adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in this repository's issues, pull requests, discussions and reviews is expected to follow it.

## Reporting

If someone's behavior breaks the code of conduct, report the comment, issue or pull request with GitHub's **Report content** option, or contact the maintainer, [@YvesZhou-hub](https://github.com/YvesZhou-hub). Reports are kept confidential.

## Enforcement

The maintainer may edit, hide or remove contributions, lock conversations, and temporarily or permanently block participants who violate the code of conduct, following the enforcement guidelines in the Contributor Covenant.
